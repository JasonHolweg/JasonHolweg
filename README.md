# Jason Holweg

Ich automatisiere Abläufe in Betrieben mit 10–50 Mitarbeitern — Dienstplanung, Zeiterfassung
mit Lohnbüro-Export, digitale Checklisten und die Software drumherum. Webseiten baue ich auch,
oft als Einstieg. Selbstständig in Flensburg.

Seit 2024 führe ich daneben mein eigenes Café (Flora, Flensburg). Die Software dahinter —
Kasse, Dienstplanung, Zeiterfassung, digitale HACCP-Listen — habe ich selbst gebaut und
benutze sie dort jeden Tag. Was ich verkaufe, läuft vorher im eigenen Betrieb.
